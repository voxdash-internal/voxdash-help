---
title: "Editor Panel – Translation Tab"
---

The **Translation** tab allows you to create and manage multilingual versions of your questionnaire. If your questionnaire is intended for respondents who speak different languages, you can use this tab to translate all questionnaire content while maintaining a single questionnaire structure.

The Translation tab helps ensure that respondents see the questionnaire in their preferred language, making your surveys more accessible and suitable for international research and data collection projects.

> **Note:** Before translating a questionnaire, ensure that multiple languages have been added to the questionnaire's metadata.

## Accessing the Translation Tab

To manage questionnaire translations:

1. Open your questionnaire in the **Editor Panel**.
2. Select the **Translation** tab.

The Translation tab displays all languages currently associated with the questionnaire and allows you to manage translations for each one.

## Viewing Available Languages

The Translation tab lists every language configured for the questionnaire.

For each language, you can:

* View translated content.
* Edit existing translations.
* Translate new questions.
* Review untranslated items.

This allows you to manage all questionnaire translations from a single location.

## Translating Questions Manually

You can manually translate each questionnaire element into the selected language.

Common translatable content includes:

* Questionnaire title
* Questionnaire description
* Page titles
* Question titles
* Question descriptions
* Answer choices
* Validation messages
* Button labels (where applicable)
* Other translatable text elements

Manual translation provides complete control over wording and is recommended when precise terminology or localized phrasing is required.

## AI Translation

To speed up the translation process, VoxDash provides an **AI Translation** feature.

Instead of translating each question individually, you can automatically translate the entire questionnaire into the selected language.

The AI translation feature can translate:

* Questionnaire titles
* Question titles
* Descriptions
* Answer options
* Other supported text elements

After the translation is complete, review the translated content to ensure it matches your organization's terminology and language standards before publishing the questionnaire.

> **Tip:** AI translation significantly reduces translation time, but manual review is recommended for industry-specific terms, product names, and technical content.

## Adding a New Language

If the required language is not already available, you can add it directly from the Translation tab.

To add a new language:

1. Click **Add Language**.
2. Select the desired language.
3. Save your changes.

The selected language is automatically added to the questionnaire's **Metadata**.

> **Important:** Adding a language to the questionnaire does **not** automatically make every question available in that language.

To include questions in the new language, you must assign the appropriate **Multi-Language** tag to each question that should appear in that language.

Questions without the corresponding language tag will not be included when exporting or displaying that language-specific version of the questionnaire.

## Importing and Exporting Translations

The Translation tab supports importing and exporting translations using **CSV** files.

### Export Translations

You can export the questionnaire translations as a CSV file.

Exporting translations is useful for:

* Sending translations to professional translators.
* Reviewing translations offline.
* Maintaining translation backups.
* Editing translations in spreadsheet software.
* Reusing translations across projects.

### Import Translations

After translations have been completed or updated, you can import the CSV file back into VoxDash.

Importing allows you to quickly apply translated content without manually editing each question.

This workflow is especially useful for large questionnaires or when working with external translation teams.

## Translation Workflow

A typical multilingual workflow consists of the following steps:

1. Create the questionnaire.
2. Add the required languages to the questionnaire.
3. Assign **Multi-Language** tags to the relevant questions.
4. Open the **Translation** tab.
5. Translate the questionnaire manually or use **AI Translation**.
6. Review and edit translated content as needed.
7. Export or import translations using CSV files if collaborating with external translators.
8. Preview the questionnaire in each language to verify translations before publishing.

## Best Practices

To ensure high-quality multilingual questionnaires:

* Add all required languages before beginning the translation process.
* Apply **Multi-Language** tags consistently to questions intended for each language.
* Use **AI Translation** to accelerate the initial translation, then review the results manually.
* Verify that product names, brand names, and technical terminology are translated correctly.
* Export translations to CSV when collaborating with professional translators.
* Preview the questionnaire in every supported language to ensure formatting, layout, and translations display correctly.
* Revalidate questionnaire logic after translating to ensure that translated content does not affect question flow or usability.

## Summary

The **Translation** tab is the central location for managing multilingual questionnaires in VoxDash. It enables you to add new languages, translate questionnaire content manually or with AI assistance, and import or export translations using CSV files. Combined with the **Multi-Language** question tags, the Translation tab helps you efficiently create and maintain language-specific versions of your questionnaire while keeping a single, centralized questionnaire structure.
