Every questionnaire in VoxDash is made of one or more **versions**. A version is a complete copy of the questionnaire: its questions, logic, translations, tags, and settings.

Versions let you:

- keep a snapshot before making large changes,
- publish one version while you keep working on another,
- keep a published version unchanged and traceable for as long as data collected with it exists,
- go back to an earlier version and continue from there.

## Version Basics

### Version Names

Each version has a **name**, such as `Version 1`, `Before pilot changes`, or `Q4 wave`. You choose the name when you create a version, and you can rename it later (see [Rename a Version](#rename-a-version)). Version names must be unique within a questionnaire and can be up to 255 characters long.

Versions can also have an optional **note** that explains why the version was created or what changed.

<Tip>
  When you import a questionnaire from a file with AI processing, VoxDash keeps the intermediate results as versions, for example **Step 1: Programmatic Generation**, **Step 2: AI Refinement**, and **Step 3: Logic Validation**. Their notes describe what each step did. See [Import Progress](/Questionnaire-Builder/Import-Review).
</Tip>

### Version Types

| Type | Badge | Can it be edited? |
| --- | --- | --- |
| **Editable** | Editable | Yes. Changes save automatically while you work. |
| **Published** | Published | No. The version was published for data collection and is permanently sealed. |
| **Published for AI-CATI** | Published for AI-CATI | No. The version was published for use in [AI-CATI](/AI-CATI/AI-CATI-Overview) studies and is permanently sealed. |

Two more badges can appear next to a version:

- **Active** — the version that opens when anyone opens the questionnaire. There is always exactly one active version.
- **Lock icon** — the version is locked. Published versions are always locked. An editable version can be locked temporarily (see [Lock and Unlock](#lock-and-unlock)).

<Warning>
  Publishing **seals** a version permanently. A sealed version can never be edited, unlocked, or renamed. To change it, create a new version from it.
</Warning>

## Versions Panel in the Editor

Select **Versions** in the editor toolbar to open the versions panel.

<Frame>
  <img src="/images/QB/d-ed-versions-drawer.png" alt="Versions panel in the editor" style={{ borderRadius: '0.5rem' }} />
</Frame>

The panel shows:

- **Currently viewing** — the version on your canvas, and whether you are **Editing** it or it is **Read-only**.
- Filters for **All**, **Editable**, and **Published** versions.
- A card for each version with its name, type, lock state, creation date, author, number of questions, the version it is **Based on**, and its note. The version on your canvas is marked **Viewing now**.
- **View full history**, which opens the [Version History page](#version-history-page).

Each version card has these actions:

| Icon | Action | What it does |
| --- | --- | --- |
| Pencil | **Rename version** | Changes the version name. |
| Two arrows | **Switch to version** | Makes this version the active version and opens it in the editor. |
| Branch | **New version from this** | Creates a new editable version that starts as a copy of this one. |
| Trash | **Delete** | Deletes the version, when allowed (see [Delete a Version](#delete-a-version)). |

## Version History Page

The **Version History** page lists every version of the questionnaire in a table. Open it from **View full history** in the versions panel, or from **Version History** in the row menu of the [questionnaire list](/Questionnaire-Builder/Questionnaire-List).

<Frame>
  <img src="/images/QB/d-ver-history-page.png" alt="Version history page" style={{ borderRadius: '0.5rem' }} />
</Frame>

| Column | Description |
| --- | --- |
| **Version** | The version name. Select a row to open that version: an editable version becomes the active version and opens for editing; a sealed version opens as a read-only preview. |
| **Type** | Editable, Published, or Published for AI-CATI, with a lock icon when the version is locked. You can filter by type. |
| **Questions** | The number of questions in that version. |
| **Created** | When the version was created. |
| **Author** | Who created the version. |
| **Lineage / Based on** | The version it was created from, if any. |
| **Version note** | The note entered when the version was created. |
| **Actions** | Switch to version, New version from this, Rename, and Delete. The active version shows a check mark instead of **Switch to version**. |

## Preview Another Version

You can look at a version without making it the active one — for example, when you open a sealed version from the history page. While you preview, the canvas shows that version **read-only**, and a yellow banner says that this isn't the version you are editing.

<Frame>
  <img src="/images/QB/d-ver-preview-mode.png" alt="Previewing an older version in the editor" style={{ borderRadius: '0.5rem' }} />
</Frame>

From the banner you can:

- **Edit this version** — make the previewed version the active version so you can edit it (editable versions only).
- **New version from…** — create a new editable version based on the previewed one (sealed versions).
- **Close preview** — go back to the active version.

<Note>
  **Save as version** is unavailable while you preview another version. Close the preview first.
</Note>

## Save as Version

Use **Save as version** to keep a snapshot of the questionnaire as it is right now. It is in the editor toolbar when the active version is editable.

<Frame>
  <img src="/images/QB/d-ver-save-as.png" alt="Save as version dialog" style={{ borderRadius: '0.5rem', maxWidth: '480px' }} />
</Frame>

<Steps>
  <Step title="Open Save as version">
    In the editor toolbar, select **Save as version**.
  </Step>
  <Step title="Name the snapshot">
    Optionally enter a **Version name** (for example, *Before pilot changes*) and a **Note** describing what changed.
  </Step>
  <Step title="Save">
    Select **Save version**.
  </Step>
</Steps>

The snapshot is saved as a separate version, and **you keep editing the active version**. Nothing is published — use **Publish** for that.

## Create a New Version From Another Version

Use **New version** when you want an editable version that starts from the content of another version — for example, to change a questionnaire that has already been published.

You can start it from:

- **Create a new version to edit** in the read-only banner of a sealed version,
- **New version from this** on a version card in the versions panel or on the history page.

<Frame>
  <img src="/images/QB/d-ver-new-from.png" alt="New version dialog" style={{ borderRadius: '0.5rem', maxWidth: '480px' }} />
</Frame>

<Steps>
  <Step title="Choose the source">
    In **Start from**, select the version to copy. The dialog confirms which version the new one will be based on.
  </Step>
  <Step title="Name the version">
    Optionally enter a **Version name** and a **Note**.
  </Step>
  <Step title="Create it">
    Select **Create version**. The new version opens straight away as the active version, and your edits save to it.
  </Step>
</Steps>

The source version is never changed. The new version's **Based on** field records where it came from.

## Rename a Version

Select the pencil icon next to a version name, or select the version badge in the editor header, then enter the new name and select **Rename**. Only the name changes — the content, status, and lock stay as they are.

<Frame>
  <img src="/images/QB/d-ver-rename.png" alt="Rename version dialog" style={{ borderRadius: '0.5rem', maxWidth: '440px' }} />
</Frame>

You can't rename a version when:

- it is **Published** or **Published for AI-CATI** (sealed),
- it is **locked**,
- it belongs to a **Mock** sample questionnaire provided by VoxDash.

## Delete a Version

You can delete an **editable** version that is **not** the active version. Select the trash icon, then confirm.

When a version can't be deleted, the trash icon is disabled; hover over it to see why:

| Reason | What it means |
| --- | --- |
| Currently editing | It is the active version. Switch to another version first. |
| Live or published | Published versions are kept permanently. |
| Locked | Unlock the version first. |
| Used by a pretest project | Test data or a pretest depends on this version. |
| Referenced by a quota or dataset | A quota group or dataset still uses this version. |

<Warning>
  Deleting a version cannot be undone.
</Warning>

## Lock and Unlock

Locking an editable version stops anyone from changing its content — useful when a questionnaire is under review or ready for sign-off.

<Frame>
  <img src="/images/QB/d-ver-lock.png" alt="Lock questionnaire confirmation" style={{ borderRadius: '0.5rem', maxWidth: '480px' }} />
</Frame>

- Select **Lock** in the editor toolbar and confirm.
- While a version is locked, you and your team can still **preview**, **export**, **generate dummy data**, manage the **team**, and **publish** it.
- Select **Unlock** to allow editing again. You can unlock at any time.

<Note>
  Lock is a temporary freeze for editable versions. Published versions are sealed instead and cannot be unlocked.
</Note>

## Publishing and Versions

Publishing works on the active version:

1. **Publish** seals the version as **Published**.
2. On a published version, the button changes to **Publish for AI-CATI**.
3. On a version published for AI-CATI, the button changes to **Create AI-CATI**, which opens the [AI-CATI study setup](/AI-CATI/AI-CATI-Overview) with this version selected.

See [Publish a Questionnaire](/Questionnaire-Builder/Publish-questionnaire) for the checks VoxDash runs before publishing.

## Summary

- A questionnaire has one **active** version and any number of earlier versions.
- **Editable** versions save automatically; **Published** and **Published for AI-CATI** versions are permanently sealed.
- **Save as version** keeps a snapshot while you continue editing.
- **New version from…** creates an editable copy of any version, including a sealed one.
- You can **preview** any version read-only, **switch** the active version, **rename** unsealed versions, and **delete** non-active editable versions.
- **Lock** temporarily freezes an editable version.
