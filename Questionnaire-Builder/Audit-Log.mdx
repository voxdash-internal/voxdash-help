---

The **Audit log** records the activity on a questionnaire: who made a change, what they changed, and when. Use it to review a questionnaire's history before publishing, to answer "who changed this?", or for compliance reviews.

## Open the Audit Log

In the Questionnaire Editor, select **Audit log** in the toolbar, next to **Team** and **Quota**.

The audit log is read-only, so everyone who can open the questionnaire can view it. It is not available while a questionnaire is still being created.

## Filter the Activity

| Filter | Options |
| --- | --- |
| **Period** | Last 7 days, last 30 days (default), last 90 days, or last year. |
| **Activity** | One or more activity types (see the table below). |
| **People** | One or more people who made changes. |
| **Search** | Free-text search in the activity. |

Activity is shown 20 entries per page, newest first. Select **Clear all** to reset the filters.

When the chosen period has no activity, the log says so and offers **Show last year**.

<Tip>
  When an entry refers to a question, select it to jump to that question in the editor.
</Tip>

## What Is Recorded

| Area | Activities |
| --- | --- |
| **Questionnaire** | Duplicated, import started, details or description updated, questions edited. |
| **Versions** | Version created, renamed, locked, unlocked, deleted, published, published for AI-CATI, restored, active version changed. |
| **Datasets** | Dataset assigned, default dataset changed. |
| **Quotas** | Quota group created, updated, duplicated, or deleted; quota cells changed; quotas imported. |

## Availability

The audit log is part of the **audit trail** feature of your subscription plan. If your plan does not include it, the dialog shows an upgrade message instead of the activity. If you don't have access to the questionnaire, you see an access-denied message.

## Organization-Wide Audit Trail

Questionnaire activity also appears in your organization's audit trail, together with activity on other data. See [Audit Trail](/Reports-&-Dashboards/Audit-Trail).
