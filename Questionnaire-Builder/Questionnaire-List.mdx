The **Questionnaire Builder** page is your central workspace for every questionnaire in your organization. From here you can see how many questionnaires you have in each state, find a questionnaire, open its versions, manage who can access it, and create a new one.

To open it, select **Questionnaire builder** in the main navigation.

<Tip>

</Tip>

## Summary Cards

Four cards at the top of the page summarize your questionnaires:

| Card | What it counts |
| --- | --- |
| **Total questionnaires** | Every questionnaire in the organization, whatever its status. |
| **Active/Published** | Questionnaires with a published version — published for data collection or for AI-CATI. |
| **Draft** | Questionnaires that are still being built and have no published version yet. |
| **Archived** | Questionnaires that have been archived. |

## Questionnaire List

The **Questionnaire list** table shows one row per questionnaire.

| Column | Description |
| --- | --- |
| **Questionnaire Name** | The questionnaire title. Select it to open the questionnaire in the editor. The name is a regular link, so you can also open it in a new browser tab. Sample questionnaires provided by VoxDash show a **Mock** badge. |
| **Status** | The current status of the questionnaire (see [Statuses](#statuses) below). |
| **Last Modified** | When the questionnaire was last changed. The list is sorted by this column by default, newest first. |
| **Questions** | The number of questions in the questionnaire. |
| **Data collection modes** | The data collection modes the questionnaire is intended for, such as telephone interviews. When there is more than one, the first mode is shown with a **+N** badge; hover over it to see them all. |
| **Created Date** | When the questionnaire was created. |
| **Organizational access** | Who in your organization can access the questionnaire, for example **Only me**. Select the person icon to change it. |
| **Access Type** | An icon showing the questionnaire's access type: public, only me, group, or user. A questionnaire that exceeds your plan's limits is marked **Over plan limit** (see the note below). |
| **Change public access** | The public access setting. Select the pencil icon to change it. |

<Frame>
  <img src="/images/QB/d-list-access-columns.png" alt="Access columns of the questionnaire list" style={{ borderRadius: '0.5rem' }} />
</Frame>

<Note>
  A questionnaire marked **Over plan limit** has been paused by the system because your organization has more items than your subscription plan allows. It is hidden from your team and from public visitors until you upgrade your plan or remove some existing access. You can filter the **Access Type** column to show only these questionnaires.
</Note>

### Statuses

| Status | Meaning |
| --- | --- |
| **Draft** | The questionnaire is still being built. Its active version can be edited. |
| **Published** | A version has been published for data collection. Published versions are sealed and can no longer be edited. |
| **Published for AI-CATI** | A version has been published for use in [AI-CATI](/AI-CATI/AI-CATI-Overview) studies. These versions are also sealed. |
| **Archived** | The questionnaire has been archived. |
| **Processing** | A file import is still running. The questionnaire becomes available once the import finishes. See [Import Progress](/Questionnaire-Builder/Import-Review). |

<Note>
  **Published** and **Published for AI-CATI** are different. Only a version **published for AI-CATI** can be used in an AI-CATI study. A version that is only **Published** must be published again for AI-CATI first. See [Publish a Questionnaire](/Questionnaire-Builder/Publish-questionnaire).
</Note>

### Search, Filter, and Columns

Use the toolbar icons in the top-right corner of the table:

- **Columns** — show or hide columns. You can also drag column headers to reorder them.
- **Filters** — add one or more filters, for example by name, status, number of questions, date range, data collection mode, or access type. Select **Remove all** to clear them.
- **Search** — quickly find a questionnaire by name.

<Frame>
  <img src="/images/QB/d-list-filter.png" alt="Filter panel of the questionnaire list" style={{ borderRadius: '0.5rem' }} />
</Frame>

Sorting and filtering apply to the full list, not just the page you are viewing. When no questionnaire matches your filters, the table offers a **Clear filters** button.

## Versions Panel

Select the arrow (**›**) at the start of a row to expand it and see the questionnaire's versions without leaving the list.

<Frame>
  <img src="/images/QB/d-list-versions-panel.png" alt="Expanded row showing the questionnaire's versions" style={{ borderRadius: '0.5rem' }} />
</Frame>

For each version, the panel shows its name, type (**Editable**, **Published**, or **Published for AI-CATI**), number of questions, creation date, author, the version it was based on, and its note. The version currently in use is marked **Active**, and sealed versions show a lock icon.

Select the eye icon on a version to open it in the editor. If that version is not the active one, it becomes the active version first.

For more information, see [Questionnaire Versioning](/Questionnaire-Builder/Questionnaire-Versions).

## Row Actions

Select the **⋮** menu at the end of a row to see the actions available for that questionnaire.

<Frame>
  <img src="/images/QB/d-list-row-menu.png" alt="Row actions menu" style={{ borderRadius: '0.5rem', maxWidth: '520px' }} />
</Frame>

| Action | What it does |
| --- | --- |
| **Edit** | Opens the questionnaire in the editor. |
| **Data Project Access** | Shows the data projects linked to this questionnaire, where its responses and test data are stored, and lets you manage their access. |
| **Open Link** | Opens the questionnaire's survey link in a new tab. Only shown when the questionnaire has a link. |
| **Version History** | Opens the [Version History](/Questionnaire-Builder/Questionnaire-Versions#version-history-page) page. |
| **Duplicate** | Creates a copy of the questionnaire. The copy is named after the original, with a "copy" suffix. |
| **Delete** | Permanently deletes the questionnaire after you confirm. Deleted questionnaires cannot be recovered. If VoxDash cannot delete the questionnaire, the message explains why. |

<Note>
  **Edit**, **Data Project Access**, **Duplicate**, and **Delete** are unavailable while a questionnaire is **Processing**, or when you only have read access to it. The reason is shown under the action name in the menu.
</Note>

<Warning>
  **Duplicate** creates a new questionnaire, which counts toward your plan's questionnaire limit. If the limit is reached, you will see a message with a link to upgrade your plan.
</Warning>

## Create a Questionnaire

Select **Create new questionnaire** in the top-right corner. Then choose how to create it:

- **Create manually** — build the questionnaire from scratch with the drag-and-drop editor.
- **Upload file** (Beta) — import an existing questionnaire from a Word, Excel, PDF, or SPSS file, either from your device or from the VoxDash library.

<Frame>
  <img src="/images/QB/d-list-create.png" alt="Create new questionnaire dialog" style={{ borderRadius: '0.5rem' }} />
</Frame>

If your organization has reached its questionnaire limit, the dialog tells you and links to your subscription.

For step-by-step instructions, see [Create a Questionnaire](/Questionnaire-Builder/Create-questionnaire).
