After you create a questionnaire—either manually or by importing a supported file—you are automatically redirected to the **Editor Panel**.

The **Designer** tab is the main workspace for building, editing, and configuring your questionnaire. From this tab, you can add and organize questions, configure questionnaire behavior and appearance, define conditional logic, manage quotas, estimate the **Length of Interview (LOI)**, generate **Text-to-Speech (TTS)** audio, and prepare the questionnaire for data collection.

Whether you are creating a simple customer feedback survey or a complex multilingual market research questionnaire, the Designer tab provides the tools you need to create and manage the questionnaire from a single workspace.

## Designer Tab Layout

The Designer tab is divided into four main areas:

* **Top Toolbar** – Provides quick access to questionnaire management tools, collaboration, quotas, search, preview, versions, export, and other actions.
* **Question Library (Left Panel)** – Contains the available question types that you can add to the questionnaire.
* **Questionnaire Canvas (Center)** – The main design area where you add, edit, arrange, and organize questionnaire pages and questions.
* **Properties Panel (Right Panel)** – Displays settings for the questionnaire, page, or question currently selected.

The contents of the **Properties Panel** change depending on what you select in the Questionnaire Canvas.

## Top Toolbar

The **Top Toolbar** provides quick access to frequently used questionnaire management and design tools.

The available tools include:

* Overview
* Team
* Quota
* Preview
* View in VoxDash
* Export
* Versions
* Lock Questionnaire
* Search and Filter

Each tool serves a different purpose in the questionnaire development workflow.

### Questionnaire Overview

The **Overview** panel provides a high-level summary of the questionnaire and helps you quickly understand its structure and configuration.

The panel displays key statistics such as:

* Total number of questions
* Question types used
* Number of tagged questions
* Number of questions containing logic
* Other questionnaire-related metrics

Each statistic is displayed as an interactive card.

Clicking a card automatically filters the questionnaire and displays the questions associated with that statistic.

For example, you can quickly find:

* All **Radio Button** questions
* All **Demographic** questions
* Questions containing conditional logic
* Questions with validation rules
* Questions assigned specific tags

#### When to use Overview

The Overview panel is particularly useful when working with large questionnaires. Instead of manually searching through every page, you can use the statistics to identify specific types of questions or configurations that require review.

For example, before publishing a questionnaire, you can use Overview to identify questions containing logic and review them for potential configuration issues.

The **Quota** button opens the **Quota Management** page.

From the Quota Management page, you can:

* Create quota groups

* Configure quota targets
* Validate quota configurations
* Import quotas
* Export quotas

Only questions that have been tagged as **Quota** are available for quota configuration.

For example, if you have a question asking respondents for their **Gender**, you can tag that question as a Quota question and use its answer options to define quota targets.

### Lock the Questionnaire

The **Lock Questionnaire** feature prevents changes to the questionnaire content.

When a questionnaire is locked, you and your team can still perform actions such as:

* Previewing the questionnaire
* Exporting the questionnaire
* Generating data
* Publishing the questionnaire

However, editing the questionnaire content is disabled while the questionnaire is locked.

<Frame>

</Frame>

You can unlock the questionnaire at any time to continue editing.

#### When to lock a questionnaire

Locking is particularly useful when the questionnaire has been finalized and you want to prevent accidental changes before or during data collection.

## Search and Filter

As questionnaires grow in size and complexity, finding a specific question can become difficult.

The **Search and Filter** tools allow you to quickly locate questions based on their content, type, tags, language, or other questionnaire metadata.

Available filtering options include:

* Search
* Sections
* Mode
* Language
* Screener

<Frame>
  <img src="/images/QB/qsearch" alt="Designer Tab" style={{ borderRadius: '0.5rem' }} />
</Frame>

### Search

Use **Search** to find questions based on:

* Question ID
* Question title

For example, if you know the question ID or part of the question title, enter it into the search field to quickly locate the question.

### Sections

The **Sections** filter displays questions assigned to a specific **Section Tag**.

This is useful when a questionnaire contains multiple sections and you want to focus on questions belonging to a specific section.

### Mode

The **Mode** filter allows you to display questions based on their assigned **Data Collection Mode**.

This is particularly useful when the same questionnaire supports multiple methods of data collection.

### Language

The **Language** filter displays questions associated with a selected language using the **Multi-Language** tag.

This allows you to review and edit content for a specific language without having to navigate through the entire questionnaire.

### Screener

The **Screener** filter displays only questions marked as **Screener** questions.

Screener questions are commonly used at the beginning of a questionnaire to determine whether respondents meet specific eligibility criteria.

> **For detailed information, refer to the** **[Search and Filter documentation](/Questionnaire-Builder/search-filter)**.

## Questionnaire Canvas

The **Questionnaire Canvas** is the central workspace of the Designer tab.

This is where you build the questionnaire structure and organize its content.

From the canvas, you can:

* Add questions
* Edit questions
* Reorder questions
* Create and manage pages
* Select individual questions
* Select pages
* Review the questionnaire structure
* Apply page-level or question-level settings

The canvas provides a visual representation of the questionnaire structure, making it easier to understand how questions and pages are organized.

When you select an item in the canvas, its corresponding settings are displayed in the **Properties Panel**.

## Properties Panel

The **Properties Panel** is located on the right side of the Designer tab.

The content of this panel changes based on the item currently selected.

* If **no question is selected**, the panel displays **Questionnaire Settings**.
* If a **page is selected**, the panel displays **Page Settings**.
* If a **question is selected**, the panel displays the settings for that specific question.

This allows you to configure the questionnaire at different levels without leaving the Designer tab.

### Questionnaire Settings

When no question is selected, the Properties Panel displays the **Questionnaire Settings**.

These settings control the overall behavior, appearance, navigation, data handling, and respondent experience of the questionnaire.

#### General Settings

The **General Settings** section contains basic questionnaire properties.

**Questionnaire Title**

The **Questionnaire Title** is the main title associated with the questionnaire.

It can be displayed to respondents when the **Show Title and Description** option is enabled.

**Questionnaire Description**

The **Questionnaire Description** provides additional information about the questionnaire.

You can use it to:

* Introduce the survey
* Explain its purpose
* Provide instructions
* Give respondents additional context

**Show Title and Description**

Controls whether the questionnaire title and description are displayed to respondents.

**Read-Only Questionnaire**

Enables read-only behavior for the questionnaire.

When enabled, respondents cannot modify questionnaire answers.

This option can be useful when the questionnaire is being used to display existing information rather than collect new responses.

**Questionnaire Language**

Specifies the language currently displayed in the editor.

For multilingual questionnaires, selecting a language allows you to edit and review the questionnaire content for that language.

**Limit to One Response**

Restricts respondents to a single questionnaire submission.

This option can be useful for surveys where each respondent should submit the questionnaire only once.

**Questionnaire Width Mode**

Controls how the questionnaire width is displayed.

Available options include:

* **Auto** – Automatically determines the appropriate width.
* **Static** – Uses a fixed questionnaire width.
* **Responsive** – Adjusts the questionnaire layout according to the available screen size.

The estimated interview length is calculated using factors such as:

* Question types
* Data collection method
* Configured timing multipliers

LOI is particularly useful for identifying questionnaires that may be too long and could negatively affect respondent completion rates.

For example, a dataset may use values such as **99 = Don't Know** or **98 = Refused**.

## Recommended Questionnaire Design Workflow

A typical workflow in the Designer tab is:

1. **Add questions** from the Question Library.
2. **Organize questions** into pages and sections.
3. **Configure question settings** from the Properties Panel.
4. **Add tags** for features such as sections, languages, screeners, quotas, and data collection modes.
5. **Configure conditions and questionnaire logic**.
6. **Configure questionnaire appearance and navigation**.
7. **Set validation and data-handling rules**.
8. **Configure LOI** to estimate the expected interview duration.
9. **Configure TTS** if audio is required.
10. **Configure quotas** if response distribution needs to be controlled.
11. **Preview the questionnaire** and test the respondent experience.
12. **Review and save a version** before making major changes.
13. **Lock the questionnaire** when editing should no longer be allowed.
14. **Publish or use the questionnaire for data collection**.

Following this workflow helps ensure that both the questionnaire content and its underlying behavior are reviewed before data collection begins.

## Summary

The **Designer** tab is the central workspace for creating, configuring, testing, and managing questionnaires in VoxDash.

From the Designer tab, you can:

* Build questionnaires using a wide range of question types.
* Organize questions into pages and sections.
* Search and filter questions using content, tags, language, mode, and other criteria.
* Configure questionnaire-wide settings for appearance, navigation, validation, and data handling.
* Configure page-level and question-level behavior.
* Create conditional logic using conditions, custom variables, and triggers.
* Manage multilingual questionnaires.
* Estimate the **Length of Interview (LOI)**.
* Generate **Text-to-Speech (TTS)** audio.
* Create and manage **Quota Groups**.
* Preview questionnaires before data collection.
* View questionnaires in VoxDash.
* Export questionnaire definitions.
* Create and manage questionnaire versions.
* Lock finalized questionnaires to prevent accidental changes.
* Configure respondent navigation, progress indicators, timers, and Thank You pages.

The Designer tab provides a centralized environment for building professional, scalable, and highly configurable questionnaires for **data analytics, market research, customer feedback, and eCommerce use cases**.

> **Best practice:** Before publishing or using a questionnaire for data collection, always preview it and test its questions, conditions, validation rules, navigation, quotas, LOI, and other relevant settings. This helps ensure that the questionnaire behaves as intended and provides a clear and consistent experience for respondents.
